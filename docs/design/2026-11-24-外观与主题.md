# 外观与主题（背景、卡片透明度、主题）

现状设计稿，随代码更新。决定的来龙去脉在任务记录“2026-11-23-NotePulse外观与主题”（用户的知识库，不在仓库里）。

## 入口与面板

- 编辑看板时，页头编辑工具的纯图标那一层：撤销、整理、**外观（lucide `palette`）**、更多。没有文字；“外观”是悬停提示和读屏标签。
- 点它弹出和“添加卡片”同一块底部面板（`src/view.ts` 的 `buildSheet`），标题“外观”，导航“背景”“主题”。面板上的 `data-group`（`add` / `look`）决定显示哪一组导航和内容。
- 外观组开着时点“添加卡片”：换成添加那一组，面板不收起；再点“外观”换回；外观组开着时再点“外观”收起。外观组开着时“外观”图标是按下状态（`aria-expanded="true"`、`is-open`，和“更多”菜单一样）。
- 手机和窄于 760px 的面板没有编辑入口，所以没有这个按钮；外观设置照样生效。
- 选了立刻在上面的看板生效，并存进 `data.json`；拖取色、拖滑块时只改页面，松手才保存。

## 数据（`data.json` 的 `settings.appearance`）

```json
"appearance": {
  "theme": "default" | "craft",
  "background": { "kind": "theme" | "preset" | "mine", "preset": "gradient" | "paper", "id": "<我的背景的 id>" },
  "backgrounds": [ { "id": "ab12cd", "color": "#E8DFD0" }, { "id": "ef34gh", "image": "Note Pulse/backgrounds/bg-ef34gh.jpg", "ink": "light" } ],
  "cardOpacity": 100
}
```

- 读取（`sanitizeAppearance`）：没有这个字段就是默认（默认主题、跟随主题、没有我的背景、透明度 100），已有用户升级后外观不变，不升 `SETTINGS_VERSION`。不认识的主题编号退回 `default`（别的设备可能装着多一套主题的版本）；背景选择找不到对应项退回“跟随主题”；颜色只认 `#RRGGBB`（存成大写）；图片路径只认库里的相对路径（不以 `/` 开头，没有 `..`、`.` 段，没有反斜杠、协议、盘符，不超过 300 字）；颜色和图片只能二选一；id 不能空、不超过 32 字、不能重复；最多 8 个，多的丢掉；透明度取整后夹在 0 到 100。
- 颜色浅色深色共用一个值。`ink` 是添加图片时按图片上部 35% 的平均颜色算好的（`dark` 深色字 / `light` 浅色字）。
- 别的设备改了外观、`data.json` 同步过来时，`onExternalSettingsChange` 直接换上。

## 主题和背景怎么落到页面上

- 主题表 `THEMES`、预设表 `BACKGROUNDS` 在 `src/appearance.ts`。一套主题 = 编号 + 浅色令牌表 + 深色令牌表（两张表的键必须一样，测试会查）。默认主题不覆盖任何令牌。将来加一套（比如“卡片层级与平铺”）就是在表里加一项，数据格式不变。
- 样式规则由 `buildCss()` 生成，写进 `styles.css` 的 `themes:start` 到 `themes:end` 之间（`node scripts/build-themes.mjs`），`tests/appearance.test.ts` 检查两边一致。**不在运行时往页面里插 `<style>`**：社区插件审查（`eslint-plugin-obsidianmd` 的 `no-forbidden-elements`）不允许。
- `appearanceLook()` 算出看板根元素（`.vp-root`）上的类名和自定义属性：`vp-theme-<id>`；`vp-bg-gradient` / `vp-bg-paper`；自选颜色 `vp-bg-color` + `vp-ink-*` + `--vp-custom`；图片 `vp-bg-image` + `vp-ink-*` + `--vp-page-image`（图片文件不在时都不加，页面退回主题自带的底色）；透明度低于 100 时 `vp-translucent` + `--vp-card-op`。
- 挂在看板根元素外面的层也带主题类名：庆祝层、拖入添加时跟手的预览、新手引导（引导层是 `tour.ts` 建在 body 上的，`view.ts` 在开始引导后补上类名）。这些层只带主题，不带背景和透明度。
- 背景只管页面底色：`--vp-page` 和光晕强度 `--vp-glow`（数字，`@property` 注册后可以过渡）。背景规则排在主题规则后面。

## 卡片透明度

- 低于 100% 才生效。卡片自己的底色挪到 `::before` 上单独降透明度，边框、文字、阴影不受影响，再加 `backdrop-filter: blur(14px) saturate(1.1)`（带 `-webkit-` 前缀）。
- 卡片里嵌套的小面板（今日写作的“本周”框、数据概览的格子……）用的是 `--vp-surface`：在卡片这一层把它换成同样透明度的底色，小面板就一起透明。移除按钮、热力图某天的详情盖在内容上，保持实心。
- 只管看板正文 `.vp-body` 里的卡片：添加面板里的预览、编辑工具、页首保持实心。
- 自选颜色或图片背景时（有 `vp-ink-*`）：卡片底色、边框、线条随透明度连续渐变到和背景明暗一致的“玻璃色”；字色在 60% 处切换（60% 及以上是主题的字色，59% 及以下是玻璃字色），切换用 240ms 的时间过渡（`--vp-ink-mix` 注册成数字）。不做随位置均匀渐变：两端一深一浅，中间必然经过灰字配灰底。
- 提醒条也在 `.vp-body` 里，但它不是卡片：自选颜色和图片背景下先垫一层主题的实心卡片底色，字色用主题自己的。

## 图片

- 系统文件选择器（界面规则允许的唯一原生控件）→ 超过 20 MB 或不是图片直接提示并放弃 → canvas 压缩到长边 1920、JPEG 质量 0.82 → `vault.createBinary` 写进 `Note Pulse/backgrounds/bg-<id>.jpg`（文件夹不在先建）→ 加进我的背景并选中。
- 显示用 `vault.getResourcePath`。看板监听 `vault` 的 `create` / `delete` / `rename`：文件没了退回主题底色，文件到了（同步过来）换上，改名时记录跟着改。
- 从我的背景里删掉图片，库里的文件不删（用户的文件）。

## Craft 主题

令牌表里的部分：暖纸色页面、白色平涂卡片、16px 卡片圆角、8px 小控件圆角、暖色阴影、没有光晕。令牌表达不了的部分在 `styles.css`“外观”一节：字体 Avenir Next；卡片内边距 22px 24px（紧凑卡和写作回顾卡除外）；英雄卡描边；浏览时悬停上抬 2px（`translate`，编辑时不上抬）。强调色仍跟随 Obsidian。

## 动效

- 页面底色、光晕：`--vp-t-base` + `--vp-ease` 过渡；拖取色、拖透明度时（根元素带 `is-picking`）不带过渡。
- 换主题、换成或离开图片背景：标题区和卡片网格从 35% 透明度淡入（`--vp-t-enter` + `--vp-ease-out`）。
- 取色界面展开收起：宽度和透明度过渡。滑块和取色圆点按下放大 1.18 倍（`--vp-t-fast` + `--vp-ease-pop`）。删除按钮悬停淡入。
- 面板弹起、导航底色滑动、格子依次浮起、对勾弹出：沿用添加面板的。
- 全部挂在 `.vp-motion` 下：设置里关了动效或系统“减弱动态效果”时直接到位。

## 文件

- `src/appearance.ts`：数据、主题表、预设表、读取、生成样式、类名计算、取色换算（不引用 obsidian）。
- `src/appearance-panel.ts`：面板里“背景”“主题”两个分类、取色界面、滑块、添加图片。
- `src/view.ts`：编辑栏按钮、面板换组、把外观挂到根元素、监听图片文件。
- `styles.css`：`themes:start` … `themes:end`（生成的），“外观”一节。
- `scripts/build-themes.mjs`；`scripts/preview/appearance.*`（浏览器预览，示例数据，不算验收）。
