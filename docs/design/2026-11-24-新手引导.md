# 新手引导（现状）

2.0 起看板有一套分步引导：整屏遮罩，挖洞高亮真实的界面，旁边一张提示卡（第几步、标题、正文、上一步 / 下一步 / 跳过），需要编辑模式或添加面板的步骤自动进入、自动展开，结束后回到开始前的状态。本文记录 2026-11-24 跟着新界面（页头编辑工具、底部添加面板）重做后的样子。

代码：步骤和判断在 `src/tour-logic.ts`（纯函数，测试在 `tests/tour.test.ts`），画界面在 `src/tour.ts`，找目标和触发在 `src/view.ts`（`autoTour`、`startTour`、`tourFind`）。

## 谁看到哪套

`data.json` 的 `guideSeen` 记着看过哪一版，当前记号 `GUIDE_VERSION = "2.2"`（只是记号，不必等于发版号）。`autoTourKind(seen, wide)` 决定自动弹哪套：

| guideSeen | 宽面板（电脑，看板宽 760px 以上） | 手机、窄面板 |
| --- | --- | --- |
| 空（新装、从没看过） | 完整引导 | 只看版 |
| 旧记号（如 `"2.0"`） | 新增内容的短引导 | 不弹，也不记成看过，等第一次在宽面板打开 |
| 当前记号 | 不弹 | 不弹 |

- 命令“查看新手引导”（id `show-guide`）、编辑时页头“更多”里的“新手引导”、设置里“新手引导”的按钮：总是完整引导（窄面板上是只看版）。
- 看完或跳过都把 `guideSeen` 记成当前记号，随库同步，换设备不再弹。
- 撒花只在这个面板马上要自动弹引导、或引导正在进行时让路。

## 三套步骤

完整引导（12 步）：欢迎 → 问候 → 提醒（可选）→ 铅笔 → 拖动卡片 → 拖右下角 → 切换（可选）→ 页头的编辑工具 → 添加卡片按钮 → 添加面板 → 完成 → 结束。

短引导（6 步）：编辑看板换了样子 → 提醒（可选）→ 页头的编辑工具 → 添加面板 → 完成 → 结束。

只看版（5 步）：欢迎 → 问候 → 提醒（可选）→ 卡片（可选）→ 结束。

“可选”是目标找不到时跳过（没有提醒色块、没有带切换的卡片），步数跟着少。

## 高亮目标

| 目标 | 元素 |
| --- | --- |
| greeting | 页首问候 |
| alerts | 提醒色块那一行（没有色块时跳过） |
| editBtn | 页头的铅笔 |
| card / firstCard | 看板上第一张卡 |
| handle | 第一张卡的右下角 |
| switch | 第一张带切换的卡上的切换组 |
| tools | 页头编辑工具里纯图标的一层：撤销、整理、更多（`.vp-edit-icons`，不含添加卡片和完成） |
| addBtn | 页头的“添加卡片” |
| addPanel | 底部弹起的添加面板 |
| doneBtn | 页头的“完成” |

## 写法约定

- 提示卡正文就是讲这一步的内容，不另加说明小字；不在文字里写版本号，不说“编辑栏”。
- 再看一遍的入口写成：命令面板搜“新手引导”，或编辑时点页头的“更多”再点“新手引导”。
- 提醒那一步提一句每种提醒能在设置的“打卡与热力图”里单独开关；不高亮设置页。

## 以后界面再大改

把 `GUIDE_VERSION` 换成新记号，在 `tourSteps` 的 `news` 里写变了的地方；看过旧记号的人会自动看一次短引导，新装照旧看完整引导。预览：`node scripts/preview/build.mjs` 后起本地服务，打开 `scripts/preview/index.html?tour=1`（完整）或 `?tour=news`（短引导）。
